## 🚀 شروع سریع

### استفاده آنلاین
به [hesabist-app.ir](https://hesabist-app.ir/) مراجعه کنید

### نصب روی موبایل
1. سایت رو در مرورگر باز کنید
2. گزینه "افزودن به صفحه اصلی" رو بزنید
3. اپلیکیشن نصب میشه!

### اجرای محلی
```bash
# کلون کردن
git clone https://github.com/mmdfathian/hesabist.git
cd hesabist

# اجرای سرور محلی
python -m http.server 8000

# باز کردن در مرورگر
# http://localhost:8000
```

## 🛠️ توسعه

### پیش‌نیازها
- مرورگر مدرن (Chrome, Firefox, Safari)
- Node.js (اختیاری برای تست)

### ساختار پروژه
```
hesabist/
├── index.html      # صفحه اصلی
├── style.css       # استایل‌ها
├── script.js       # منطق برنامه
├── sw.js           # Service Worker
├── manifest.json   # PWA manifest
├── CNAME           # تنظیمات دامنه
└── tests/          # تست‌ها
```

### اجرای تست‌ها
```bash
npm test
```
